# DATE & TIME API

1. **java.timeLocalDate** -> This represents only the time according to the ISO calendar.
2. **java.time.Localime** -> This represents only the time in a human-readable manner
3. **java.time.LocalDateTime** -> Both the ddate and time without having a time zone will be handled here. _this is a combination of LocalDate and LocalTime_
4. **java.time.ZonedDateTime** -> LocalDateTime combines with the time zone provided using _ZoneId class_.
5. **java.yimeoffsetDateTime** -> Handles a date and Time with a corresponding time zone.offsetfrom Greenwich/UTC, Without a time zone
